# OBA AgroTech — Premium Website

A mobile-first premium brand website for OBA AgroTech.

## Quick setup

1. Upload all files to your GitHub repository.
2. Open `script.js`.
3. Replace:
   `234XXXXXXXXXX`
   with your WhatsApp number **without + or spaces**.
4. Enable GitHub Pages from the repository settings.
5. The site uses online images from Unsplash, so an internet connection is needed for the photos.
